# ModuleHandbook – Einstieg

Dieses Repository enthält die Modulhandbücher mehrerer Studiengänge. Es gibt zwei Wege zur Mitarbeit.

## A. Das technische System weiterentwickeln

1. Öffnen Sie das Repository: https://github.com/JirkaDellOro/GMB_Handbook
2. Geben Sie einer neuen ChatGPT-Instanz die Datei [CHATGPT_HANDOVER.md](CHATGPT_HANDOVER.md) und Zugriff auf das Repository.
3. Beschreiben Sie den gewünschten Änderungsauftrag.
4. Lassen Sie die KI vor Änderungen den aktuellen Stand prüfen.

Die Handover-Datei vermittelt Projektwissen und verbindliche Arbeitsregeln. Sie ersetzt nicht die Prüfung des aktuellen Repository-Zustands.

## B. Ein Modulhandbuch aus einem PDF übertragen

1. Öffnen Sie eine KI, die PDFs lesen und ZIP-Dateien erstellen kann.
2. Laden Sie das PDF und die Datei [PDF_TO_MODULEHANDBOOK.md](PDF_TO_MODULEHANDBOOK.md) hoch.
3. Bitten Sie die KI, die Anweisung vollständig auszuführen. Sie benötigt Lesezugriff auf das öffentliche Repository: https://github.com/JirkaDellOro/GMB_Handbook
4. Prüfen Sie die von der KI ausgewiesenen offenen Fragen. Fehlende oder unklare Angaben dürfen nicht geraten werden.
5. Senden Sie mir das erzeugte ZIP-Paket zur Prüfung und Integration.

Für diesen Weg sind keine Programmierkenntnisse und kein Schreibzugriff auf GitHub erforderlich.

**Grundsatz:** Das PDF ist die fachliche Quelle; bestehende Studiengänge dienen nur als technische Vorlage. Akademische Inhalte dürfen nicht ergänzt oder verändert werden, wenn sie nicht eindeutig aus dem PDF hervorgehen.
